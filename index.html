🔢 Натуральные числа и действия

💡 Натуральные числа — это 1, 2, 3, 4, 5… Обозначаются ℕ. Используются для счёта.

Свойства действий

СвойствоФормулаПример
Переместительноеa + b = b + a3 + 5 = 5 + 3
Сочетательное(a + b) + c = a + (b + c)(1+2)+3 = 1+(2+3)
Распределительноеa(b + c) = ab + ac2·(3+4) = 2·3 + 2·4

Признаки делимости

НаПризнак
2Последняя цифра чётная
3Сумма цифр делится на 3
5Оканчивается на 0 или 5
9Сумма цифр делится на 9
10Оканчивается на 0
⚠️ Порядок действий: скобки → степени → умножение/деление → сложение/вычитание.

➗ Дроби

💡 Дробь a/b: a — числитель, b — знаменатель. Показывает, сколько частей взяли из целого.

Действия с дробями

a/b + c/d = (ad + bc) / bd
a/b · c/d = ac / bd
a/b ÷ c/d = a/b · d/c = ad / bc
📝Пример: 1/2 + 1/3 = 3/6 + 2/6 = 5/6
🌟Совет: чтобы сложить дроби — приведи к общему знаменателю (НОК знаменателей).

💯 Проценты

💡 Процент = 1/100 числа. Обозначается знаком %.
p% от A = A · p / 100
Число A по его p%: A = (значение · 100) / p

Увеличение и уменьшение

ДействиеФормула
Увеличить на p%A · (1 + p/100)
Уменьшить на p%A · (1 − p/100)
📝Пример: 20% от 150 = 150 · 0,2 = 30

⚡ Степени и корни

💡 Степень aⁿ — это a, умноженное само на себя n раз.

Свойства степеней

aᵐ · aⁿ = aᵐ⁺ⁿ
aᵐ ÷ aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐ·ⁿ
a⁰ = 1 (при a ≠ 0)
a⁻ⁿ = 1/aⁿ

Квадратный корень

√(ab) = √a · √b
(√a)² = a
√(a²) = |a|
📝Пример: √18 = √(9·2) = 3√2

📏 Формулы сокращённого умножения

💡 Эти формулы обязательно надо знать наизусть!
(a + b)² = a² + 2ab + b²
(a − b)² = a² − 2ab + b²
a² − b² = (a − b)(a + b)
(a + b)³ = a³ + 3a²b + 3ab² + b³
a³ + b³ = (a + b)(a² − ab + b²)
a³ − b³ = (a − b)(a² + ab + b²)
📝Пример: 101² = (100 + 1)² = 10000 + 200 + 1 = 10201

❓ Что такое x и как его найти

💡 x — это неизвестное число. Оно называется переменной. Найти x — значит решить уравнение, то есть найти число, которое сделает уравнение верным.

🎯 Как находить x — общее правило

Главное правило: чтобы найти x, надо оставить его одного с одной стороны, а все остальные числа — перенести в другую сторону.

При переносе через знак «=» число меняет знак на противоположный!

📐 Простые случаи

УравнениеЧто делатьОтвет
x + a = bВычесть a с двух сторон: x = b − ax = b − a
x − a = bПрибавить a: x = b + ax = b + a
a · x = bРазделить на a: x = b / ax = b / a
x / a = bУмножить на a: x = b · ax = b · a
a − x = bПеренести: x = a − bx = a − b

📝 Примеры с пошаговым решением

📝Пример 1: x + 5 = 12
Переносим 5 вправо с противоположным знаком: x = 12 − 5
x = 7
📝Пример 2: 3x = 15
Делим обе стороны на 3: x = 15 / 3
x = 5
📝Пример 3: 2x − 6 = 10
Переносим −6 вправо: 2x = 10 + 6 = 16
Делим на 2: x = 8
📝Пример 4: 5(x − 3) = 20
Раскрываем скобки: 5x − 15 = 20
Переносим −15: 5x = 20 + 15 = 35
Делим на 5: x = 7

🎯 Алгоритм — 4 шага

  1. Раскрыть скобки (если есть).
  2. Собрать все x в одну сторону, числа — в другую (при переносе менять знак!).
  3. Привести подобные слагаемые.
  4. Разделить обе стороны на коэффициент при x.
🌟Проверка: подставь найденный x в исходное уравнение. Если левая часть равна правой — x найден правильно!
⚠️ Частая ошибка: забыть поменять знак при переносе. Например: x + 5 = 12 → x = 12 − 5 (а НЕ 12 + 5!).

🟰 Линейные уравнения

💡 Линейное уравнение — вида ax + b = 0, где a ≠ 0.

Алгоритм решения

  1. Раскрыть скобки.
  2. Собрать x слева, числа справа (знак меняется!).
  3. Привести подобные.
  4. Разделить на коэффициент при x.
📝Пример: 3(x − 2) = 9
3x − 6 = 9
3x = 9 + 6 = 15
x = 5
🌟Интересный факт: если a = 0, то уравнение либо не имеет решений (0 = 5), либо имеет бесконечно много (0 = 0).

🔷 Квадратные уравнения

💡 Квадратное уравнение: ax² + bx + c = 0, где a ≠ 0.
D = b² − 4ac
x₁,₂ = (−b ± √D) / (2a)
ДискриминантСколько корней
D > 0Два разных корня
D = 0Один корень
D < 0Нет действительных корней
📝Пример: x² − 5x + 6 = 0
D = 25 − 24 = 1
x₁ = (5 + 1)/2 = 3, x₂ = (5 − 1)/2 = 2

🎯 Теорема Виета

💡 Для приведённого уравнения x² + px + q = 0:
x₁ + x₂ = −p
x₁ · x₂ = q
📝Пример: x² − 7x + 12 = 0
Ищем два числа, сумма = 7, произведение = 12.
Это 3 и 4. Значит x₁ = 3, x₂ = 4.
🌟Интересный факт: Франсуа Виет был адвокатом и расшифровывал секретные коды короля!

📊 Прогрессии

💡 Прогрессия — последовательность чисел по определённому правилу.

Арифметическая прогрессия

aₙ = a₁ + d(n − 1)
Sₙ = (a₁ + aₙ) · n / 2
📝2, 5, 8, 11… d = 3. a₁₀ = 2 + 27 = 29

Геометрическая прогрессия

bₙ = b₁ · qⁿ⁻¹
Sₙ = b₁(qⁿ − 1) / (q − 1)
📝3, 6, 12, 24… q = 2. b₅ = 3 · 16 = 48

📉 Логарифмы

💡 log_a(b) — степень, в которую надо возвести a, чтобы получить b.
log_a(xy) = log_a(x) + log_a(y)
log_a(x/y) = log_a(x) − log_a(y)
log_a(xⁿ) = n · log_a(x)
log_a(1) = 0, log_a(a) = 1
📝log₂(8) = 3, потому что 2³ = 8

💡 Производная f'(x) — скорость изменения функции. Геометрически — тангенс угла наклона касательной.

Правила

⚠️ Частые ошибки

💡 Эти ошибки делают почти все!

1. Забыли поменять знак при переносе

❌✅
x + 5 = 8 → x = 8 + 5x = 8 − 5 = 3

2. Квадрат суммы

❌✅
(a + b)² = a² + b²(a + b)² = a² + 2ab + b²

3. Корень из суммы

❌✅
√(a + b) = √a + √bТак нельзя!

4. Дискриминант

D = b² − 4ac (минус, а не плюс!).

5. Неравенство на минус

При умножении на отрицательное число знак неравенства меняется: −x > 5 → x < −5.
